# 账单批量导入说明

## 模板文件

[transactions_template.csv](./transactions_template.csv)

## 字段说明

| 列名 | 必填 | 格式 | 说明 |
|---|---|---|---|
| 日期 | ✅ | YYYY-MM-DD | 例如 `2026-07-19` |
| 类型 | ✅ | 收入 / 支出 | 填写「收入」或「支出」 |
| 分类 | ✅ | 字符串 | 必须是系统已配置的分类（见管理页面） |
| 金额 | ✅ | 数字 | 大于 0，支持小数（如 `35.5`） |
| 支付方式 | ✅ | 字符串 | 必须是系统已配置的支付方式 |
| 备注 | ❌ | 字符串 | 任意描述，留空也行 |

## 使用步骤

1. 下载 `transactions_template.csv`
2. 用 Excel / WPS / Numbers / VSCode 打开
3. **清空示例数据**（保留第一行表头）
4. 按列填写自己的账单
5. 保存为 CSV（UTF-8 编码）
6. 在「全部账单」页面点击「批量导入」按钮，选择文件上传

## 重要说明

### 关于分类和支付方式

**必须先在管理页面配置好分类和支付方式**，否则导入会报错。

比如模板里写的「餐饮」「交通」「工资」，这些必须是 [管理页面](http://10.10.10.46:5391/admin) 中已经存在的分类名。

### 关于 Excel 编码

Excel 默认保存为 GBK 编码，可能导致中文乱码。建议：

- **Excel**：另存为 → 文件类型选「CSV UTF-8 (逗号分隔)」
- **WPS**：另存为 → 编码选「UTF-8」
- **Numbers**：导出 → CSV → 编码选「UTF-8」

### 关于金额

- 使用数字，不要带货币符号（`35.50` ✓，`¥35.50` ✗）
- 支持两位小数（`35.5` 和 `35.50` 都行）
- 不要用千分位（`1000` ✓，`1,000` ✗）

### 关于类型字段

| 取值 | 含义 |
|---|---|
| `收入` | 收入 |
| `支出` | 支出 |

旧版模板中的 `income` / `expense` 也仍可正常导入，以兼容已保存的文件。

### 关于错误处理

导入时如果某一行数据有问题（比如分类不存在、日期格式错），系统会：

1. **跳过该行**，不导入
2. **继续处理后面的行**，不会中断
3. **返回详细错误信息**：哪一行、什么错误

例如：

```json
{
  "success": true,
  "data": {
    "inserted": 28,
    "errors": [
      { "row": 5, "message": "category 不合法：旅行" },
      { "row": 12, "message": "amount 必须大于 0" }
    ]
  }
}
```

修正这些行后重新导入即可。

## 示例

完整示例见 [transactions_template.csv](./transactions_template.csv)，包含 5 条样本数据（涵盖收入/支出、不同分类、不同支付方式）。

## 批量导入 API（供开发者）

```
POST /api/v1/transactions/batch
Content-Type: application/json

{
  "transactions": [
    {
      "date": "2026-07-01",
      "type": "expense",
      "category": "餐饮",
      "amount": 35.5,
      "paymentMethod": "支付宝",
      "note": "午饭"
    }
  ]
}
```

响应：

```json
{
  "success": true,
  "data": {
    "inserted": 1,
    "errors": []
  }
}
```
