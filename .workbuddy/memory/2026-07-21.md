## Money_Book UI 图标体系优化

### 任务背景
用户要求基于 Frontend Design skill 检查现有 UI 组件 / 图标 / 视觉风格，替换为更符合"记账本"项目调性的图标方案。

### 现状诊断
- 项目用 Tailwind CSS + lucide-react，主色 blue-600
- 品牌图标为通用 Wallet，favicon 是占位色块，缺乏辨识度
- 业务图标（TrendingUp/Down、BarChart3、各分类图标）零散无主题感
- icons.tsx 中 PICKABLE_ICONS 仅 30 个，覆盖不全

### 主要改动
1. **`src/lib/icons.tsx` 全面重构**：
   - 围绕"记账 / 消费 / 货币"主题组织 60+ 图标
   - 按收入 / 餐饮 / 交通 / 购物 / 居家 / 娱乐 / 医疗 / 教育 / 旅行 / 家庭 / 其他 共 11 个语义分组
   - 暴露 `PICKABLE_ICON_GROUPS` + 扁平化 `PICKABLE_ICONS`
   - 保留 `credit-card` / `smartphone` 兼容映射，历史数据不会出现 broken icon
   - 注意：lucide-react 0.511.0 没有 `Taxi`，用 `CarTaxiFront` 替代

2. **新增 `src/components/BrandLogo.tsx`**：
   - SVG 自创"账本 + ¥"品牌徽标，圆角方形 + 蓝色渐变
   - 替代 Sidebar / MobileTopBar 中的 Wallet 图标

3. **`public/favicon.svg` 升级**：
   - 从"蓝底白横线"占位 → 渐变蓝 + ¥ 货币符号 + 账本脊线
   - 与 BrandLogo 视觉语言统一

4. **`src/components/Sidebar.tsx` 重写**：
   - 引入 BrandLogo 作为品牌区主视觉
   - 标题加 BookOpenText 装饰图标

5. **`src/components/IconPicker.tsx` 升级**：
   - 支持按分组展示（PICKABLE_ICON_GROUPS）
   - 搜索时跨分组过滤

6. **`src/pages/Dashboard.tsx` 微调**：
   - 结余卡片 `Wallet` → `PiggyBank`（语义更准）
   - `PlusCircle` → `Plus`（与 Transactions 统一）

7. **`src/pages/Transactions.tsx` 微调**：
   - `PlusCircle` → `Plus`

8. **`api/config/appConfig.ts` 同步**：
   - 支付方式默认图标：银行卡/花呗 → `landmark`，支付宝/微信/抖音月付 → `wallet`
   - 注释更新图标选型原则
