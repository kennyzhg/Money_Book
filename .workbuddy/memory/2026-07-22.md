## 新增 Linux 一键部署脚本 deploy-linux.sh

### 任务背景
生产环境部署在内网 10.10.10.6 / Debian 13 / 端口 5391，代码更新后需要推送部署。已有 Windows 版 `deploy-windows.ps1`，缺一个对等的 Linux 脚本。

### 主要改动
- 新增 `deploy-linux.sh`（447 行，已 chmod +x）
- 功能对标 Windows 版，完整覆盖：root 检查 → Node.js 检测/安装（NodeSource for Debian/Ubuntu + rpm.nodesource.com for RHEL 系）→ 源码校验 → 停 systemd 服务 → 备份 SQLite → rsync 拷贝（排除 node_modules/dist/.git/data/.env）→ npm install + build + prune → 恢复数据库 → 生成 systemd unit（PORT 通过 Environment 注入）→ ufw/firewalld/iptables 三选一放行 → 启动 → curl 健康检查 → 输出访问地址
- 默认参数贴合用户场景：`PORT=5391`，`INSTALL_DIR=/opt/money-tracker`
- 增量更新模式：默认保留 `node_modules`，加 `--force` 清空重建
- 安全特性：升级前自动备份 `data/money.db*`，部署后自动恢复

### 关键技术点
- `api/app.ts` 在生产模式下用 Express 托管 `dist/`，所以单端口（5391）同时提供前端 + API
- systemd unit 中 ExecStart 用 `node + tsx api/server.ts`，PORT 通过 `Environment=PORT=5391` 注入，`api/server.ts` 读取 `process.env.PORT`
- Debian 13 (trixie) NodeSource 可能尚未完全支持，脚本带 fallback 到系统仓库
- 已用 `bash -n` 通过语法检查

### 部署脚本加固 - data/ 目录保护

### 修复移动端底部导航栏 fixed 定位
问题：MobileTabBar 在 flex 流中，部分移动端浏览器（iOS Safari 100vh 含工具栏、Android Chrome 工具栏折叠）导致 TabBar 不在可视区域底部。
修复：
1. MobileTabBar 改为 `fixed bottom-0 left-0 right-0 z-50`，脱离 flex 流
2. Layout.tsx `<main>` 添加 `paddingBottom: 'calc(56px + env(safe-area-inset-bottom, 0px))'` 防止被 fixed TabBar 遮挡
3. `md:hidden` 保留，桌面端不受影响
4. Vite build 验证通过

### 修复 fixed TabBar 遮挡 + 年度合计视觉统一
两层修复：
1. **遮挡修复**：将 padding 从 `<main>` 移到内部 `<div>`，避开某些浏览器对 `overflow-y:auto` 元素 `padding-bottom` 渲染不一致的问题。padding 值从 56px 提升到 64px 增加安全余量。
2. **年度合计视觉统一**：月度卡片为 `rounded-xl border border-slate-100 bg-slate-50/40`，年度合计改为相同卡片样式 + 左侧蓝色竖线装饰条标明"汇总"层级，保持最后位置。

### 第二次修复：去掉 calc+env，改用纯 Tailwind pb-20
用户反馈首次滑动仍被遮挡。根因：某些浏览器不支持 `env()`，导致 `calc(64px+env(...))` 整个声明无效，回退到 `py-4` 的 16px。修复改用纯 Tailwind `pb-20` (80px)，去掉所有 inline style 依赖。移动端 `pb-20`，桌面端 `md:pb-8` 恢复正常间距。
